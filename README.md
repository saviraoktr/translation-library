# Translation Library

A personal multilingual vocabulary library for collecting and managing translations in English, Spanish, and Indonesian.

## About the Project

Translation Library is a simple web application that allows users to build and organize their own multilingual vocabulary collection. Users can add new phrases, assign categories, search for specific entries, edit existing translations, and delete entries they no longer need.

The application also uses browser Local Storage to save entries, allowing the vocabulary collection to remain available even after the page is refreshed.

## Purpose

This project was created to apply and practice the programming concepts I have learned through building a functional web application. Rather than learning concepts individually, I wanted to put them into practice by developing a project from scratch, combining HTML, CSS, and JavaScript to create an interactive application.

It also serves as an opportunity to understand how different parts of a web application work together, from structuring the interface and styling its layout to handling user interactions, managing data, and storing information.

## Features

- Add English, Spanish, and Indonesian translations.
- Assign categories to vocabulary entries.
- Search for specific English phrases.
- Filter entries by category.
- Edit existing translations.
- Delete entries with a custom confirmation modal.
- Detect duplicate English phrases.
- Save entries using Local Storage.

## Built With
